DARSHU BIRTHDAY CARD

Open index.html in a modern browser.

The card uses the uploaded photos and includes an optional YouTube-powered player for “Khat” by Navjot Ahuja. The first tap opens the experience; the music button can start the official YouTube track.

For hosting: upload this whole folder (index.html + assets/) to any static host such as Vercel, Netlify, GitHub Pages, or similar. Keep the assets folder beside index.html.
